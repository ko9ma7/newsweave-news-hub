수집부터 정리까지

GitHub Actions가 정기 실행하고, 브라우저는 생성된 정적 카탈로그를 읽어 빠르게 검색합니다.

01SourceGoogle News RSS / RSS / Atom
02Collect카테고리·검색식별 기사 수집
03Normalize중복 제거와 공통 스키마 변환
04Catalog정적 JSON 검색 인덱스 생성
05Collections키워드·카테고리 규칙 자동 저장
완전히 새 저장소로 시작합니다.

처음 배포 후 Actions가 설정된 분야의 새 뉴스부터 수집하며, 새 분야는 config/sources.json에 한 줄 추가하는 방식으로 확장할 수 있습니다.
